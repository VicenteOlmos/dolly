# Support

## Getting help

- Start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md) for setup, testing, and pull request expectations.
- Search [existing issues](https://github.com/VicenteOlmos/dolly/issues) before opening a new one.
- Use the [bug report](https://github.com/VicenteOlmos/dolly/issues/new?template=bug_report.yml) or [feature request](https://github.com/VicenteOlmos/dolly/issues/new?template=feature_request.yml) templates for structured intake.

## Security issues

Do not open public issues for vulnerabilities.

Report security problems privately through [GitHub private vulnerability reporting](https://github.com/VicenteOlmos/dolly/security/advisories/new). See [SECURITY.md](SECURITY.md) for the full policy.

## Maintenance scope

Dolly is maintained in spare time. Response times vary. Only the latest release receives security fixes.
